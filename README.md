# Claude登录器

面向 Windows x64 的第三方客户端，支持账号注册和登录、兑换码充值、余额与用量查询，以及配置并启动 Claude Desktop。

## Windows 下载

- [便携版 EXE](https://github.com/ranxingzi18-create/claude-login-downloads/releases/latest/download/ClaudeLogin-Windows-x64.exe)
- [压缩包 ZIP](https://github.com/ranxingzi18-create/claude-login-downloads/releases/latest/download/ClaudeLogin-Windows-x64.zip)
- [历史版本与文件校验](https://github.com/ranxingzi18-create/claude-login-downloads/releases)

## 开始使用

1. 下载 EXE 后双击启动。若使用 ZIP，请完整解压，再双击其中的 `Launch-ClaudeLogin.cmd`。
2. 注册或登录。余额不足时，在客户端打开「续费」并输入兑换码。
3. 安装 Claude Desktop 后，点击「打开 Claude Desktop」完成配置。

客户端发现新版本时会提供 GitHub 下载入口。下载并运行新版本即可继续使用本机已有账号数据。

更多操作见 [客户端使用指南](CLIENT_GUIDE.md)。
